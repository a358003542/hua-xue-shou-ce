## 简介
关于一些化学上的资料信息，整理成为markdown格式，ref文件夹下的内容只是参考备用，并没有参与后续的整理维护工作。

Lange15e在处理上以表格作为核心内容来处理，辅助的文本内容也是去说明表格里面的参数和符号等。其他化学的或者数学的等等文本内容略过，后续考虑通过其他化学书籍来介绍之。
